# ⚡ RafaPayBD - Automated Solana (SOL) & BDT Payment Gateway API

A lightweight, high-speed REST API payment infrastructure built for instant Solana (SOL) and BDT deposits and automated mass payouts with live market rate conversion.

## 🚀 Key Features
- Sub-Second Verification: Instant Solana blockchain deposit detection via automated Webhooks.
- Automated Mass Payouts: Send instant withdrawals directly to user Solana wallets (~$0.001 network fee).
- Live Rate Sync: Automatic real-time BDT <-> SOL conversion engine.

## 📌 Quick API Integration
- Create Deposit: POST https://rafapaybd.com
- Instant Payout: POST https://rafapaybd.com
- Authentication Header: X-API-Key: YOUR_MERCHANT_API_KEY
